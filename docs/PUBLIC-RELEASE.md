# Public release

[简体中文](zh-CN/PUBLIC-RELEASE.md)

The owner authorized publication on 2026-10-24. The public repository uses a cleaned `main` history. The previous repository remains a private archive; its pull requests were not copied.

## Checks

- Author and committer email addresses use GitHub noreply addresses.
- A targeted scan of reachable text blobs found no private home paths, private network addresses, private-key markers, common token patterns, or the previously removed private reference.
- Manufacturer firmware, vendor tools, local environments, and decompiler output are excluded.
- The test suite passes all 72 tests. The site builds successfully. The documentation checker validates 57 documents and 435 local links.
- Chinese, English, and Japanese entry points, screenshots, and iPhone guides are included.

The scan is not a guarantee that no sensitive data exists. Historical pull-request caches remain in the private archive, outside the public repository.
