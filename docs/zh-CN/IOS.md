# 在 iPhone 上连接

[文档](README.md) · [English](../IOS.md) · [日本語](../ja/IOS.md)

通过 Bluefy 把网页连接到灯棒。iPhone 的 Safari 和 Chrome 没有原生 Web Bluetooth 接口。

以下用户提供的截图展示了 Bluefy 连接成功，不代表所有灯效和音乐功能都已逐项验证。其中两张图已遮挡设备名称或标识。截图使用英文 App 界面。

连不上或频繁断开？电池可能已耗尽，请先更换一组新电池后重试。仍无法连接时，再检查蓝牙权限，并关闭其他已连接灯棒的网页或程序。

## 1. 安装 Bluefy

在 App Store 找到 **Bluefy – Web BLE Browser**，核对开发者 **PNN Soft**。

<img src="../../web/assets/ios/install.webp" alt="安装 Bluefy" width="300">

## 2. 允许蓝牙

打开 Bluefy。系统询问蓝牙权限时，点 **Allow（允许）**。

<img src="../../web/assets/ios/permission.webp" alt="允许蓝牙" width="300">

## 3. 选择灯棒

在 Bluefy 打开 https://wuwa.south-wall.com/ 。点 **连接应援棒**，选择 **JFKJ-FBFB**。无需开启后台连接。

<img src="../../web/assets/ios/device.webp" alt="选择灯棒" width="300">

## 4. 等待蓝灯

Bluefy 显示 **connected** 时，网页可能仍在验证。等待蓝灯闪烁结束。

<img src="../../web/assets/ios/pairing.webp" alt="等待蓝灯" width="300">

## 5. 开始控制

网页显示 **已连接 JFKJ-FBFB** 后，再调色或播放灯效。

<img src="../../web/assets/ios/connected.webp" alt="开始控制" width="300">
