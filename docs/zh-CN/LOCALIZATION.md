# 语言选择

[文档](README.md) · [English](../LOCALIZATION.md) · [日本語](../ja/QUICKSTART.md)

控制页和原理页支持中文、英文和日文。翻译随页面一起构建，切换语言不需要请求额外语言文件。

## 选择顺序

页面依次使用第一个可用设置：

1. 受支持的 `lang` 查询参数：`zh`、`en` 或 `ja`。
2. 用户保存的手动选择。
3. `navigator.languages` 中第一个受支持的语言。
4. 英文。

浏览器语言标签按语言前缀匹配。例如，`zh-TW` 选择中文，`en-GB` 选择英文，`ja-JP` 选择日文。当前中文翻译使用简体字。不支持的值会被忽略。

分享指定语言时使用：

- [中文](https://wuwa.south-wall.com/?lang=zh)
- [英文](https://wuwa.south-wall.com/?lang=en)
- [日文](https://wuwa.south-wall.com/?lang=ja)

`/principles` 同样支持这个参数。明确指定的查询参数优先于已保存的选择。测试浏览器语言选择时，先移除该参数。

## 手动切换

语言控件更新页面文字和 `lang` 参数，不刷新页面，不断开灯棒，也不重新启动播放。存储可用时，浏览器会把选择保存在本地存储中。

存储不可用时，仍可在当前页切换语言。查询参数也会标明当前选择。以后不带该参数访问时，不能依赖未能保存的选择。

语言切换不改变蓝牙协议、颜色数值或灯效参数。协议名、设备名、命令字节和用户提供的文件名保持原样。

## 变更检查

使用构建后的网站，在隔离的浏览器配置中测试，避免已保存选择掩盖回退问题。

| 输入 | 预期语言 |
|---|---|
| `?lang=ja`，已保存英文 | 日文 |
| 没有受支持的查询参数，已保存中文 | 中文 |
| 未保存选择，浏览器列表为 `fr-FR`、`ja-JP`、`en-US` | 日文 |
| 未保存选择，浏览器列表为 `de-DE`、`en-GB` | 英文 |
| 未保存选择，浏览器列表为 `zh-TW`、`en-US` | 简体中文 |
| 未保存选择，浏览器列表没有受支持语言 | 英文 |
| 不支持的查询参数，如 `?lang=fr` | 继续检查已保存选择或浏览器列表 |
| 本地存储不可用 | 使用查询参数或浏览器回退；仍可手动切换 |

另检查两页的三种语言，重点看窄屏、长标签、选中项、状态消息、无障碍名称和图片描述。播放时切换语言，确认连接和灯效保持运行。

表格定义预期行为，不代表所有浏览器或实物设备都已完成这些检查。
