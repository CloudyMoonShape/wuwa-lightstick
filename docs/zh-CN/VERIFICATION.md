## 软件检查

最近一次已记录的灯效库测试通过 68 项自动检查。这个数字是历史记录。请运行 `npm test` 检查所用版本。

测试覆盖：

- 帧字节、GRB 顺序、校验和及输入边界。
- 认证顺序、完整回显、动画等待、取消及断连路径。
- 单次在途写入、待发颜色替换、慢写入及输出调度。
- 混色、白光通道保护、调光曲线及呼吸边界。
- 原生命令回复、模式切换、退出屏障、固定预设和迟到音源结果。
- 访客身份、SQL 去重、事务、请求限制、来源检查及失败处理。

模拟写入与回包不测量真实蓝牙吞吐或光学延迟。`node:sqlite` 测试不能验证生产 D1 绑定。

## 浏览器与部署记录

此前浏览器检查覆盖桌面与窄屏、深浅主题、键盘焦点、调色、灯效分类、闪光授权、本地音频播放和模拟蓝牙切换。

背景失败和延迟加载时，控件仍可操作。模拟移除蓝牙接口后，屏幕预览仍可用。这些不是 iPhone 实机测试。连接说明弹窗在 375 px 与桌面宽度下检查了开关、分页切换与复制网址。iPhone 的 Bluefy 中，旧 SDK 在弹出设备列表前就失败；修复（完整 128 位 UUID 与 `writeValue()` 后备）通过了只支持旧写入的模拟端点，待 iPhone 实机复测。

到访计数曾在隔离本地数据库中测试：32 个相同 ID 请求只增加一次。随后正式浏览器首次登记一次，刷新和新标签页复用身份。没有向生产库填入测试 ID。

此前发布时曾回读页面和部分资源，与构建内容比较。后续视觉修改后再次检查了页头对齐和文案。这些记录不代表所有浏览器或后续每次部署都已认证。

一条中国大陆 IPv6 线路的历史测量见[网络测量](PERFORMANCE.md)，不能作为全国速度保证。
