# iPhoneから接続する

[ドキュメント](README.md) · [English](../IOS.md) · [简体中文](../zh-CN/IOS.md)

Bluefyを使って、このサイトからペンライトに接続します。iPhoneのSafariとChromeには、ネイティブのWeb Bluetooth機能がありません。

ユーザー提供のスクリーンショットで、Bluefyからの接続を確認しています。すべてのエフェクトや音楽機能を検証したものではありません。2枚の画像では端末名や識別子を隠しています。アプリの表示言語は英語です。

接続できない、または接続が頻繁に切れる場合は、電池切れの可能性があります。すべての電池を新品に交換してから再試行してください。それでも接続できない場合は、Bluetoothの権限を確認し、ペンライトに接続中の他のページやアプリを閉じてください。

## 1. Bluefyをインストール

App Storeで **Bluefy – Web BLE Browser** を探します。開発元が **PNN Soft** であることを確認してください。

<img src="../../web/assets/ios/install.webp" alt="Bluefyをインストール" width="300">

## 2. Bluetoothを許可

Bluefyを開きます。Bluetoothへのアクセスを求められたら、**Allow（許可）** を選びます。

<img src="../../web/assets/ios/permission.webp" alt="Bluetoothを許可" width="300">

## 3. ペンライトを選択

Bluefyで https://wuwa.south-wall.com/ を開きます。**応援棒を接続** を押し、**JFKJ-FBFB** を選びます。バックグラウンド接続は不要です。

<img src="../../web/assets/ios/device.webp" alt="ペンライトを選択" width="300">

## 4. 青い点滅を待つ

Bluefyに **connected** と表示されても、サイトの確認が続いている場合があります。青い点滅が終わるまで待ちます。

<img src="../../web/assets/ios/pairing.webp" alt="青い点滅を待つ" width="300">

## 5. 操作を開始

サイトに **接続済み JFKJ-FBFB** と表示されたら、色やエフェクトを選びます。

<img src="../../web/assets/ios/connected.webp" alt="操作を開始" width="300">
