# 使い方

[ドキュメント](README.md) · [English](../../README.md) · [简体中文](../../README.zh-CN.md)

## 応援棒を接続

1. 電池を入れた応援棒を近くに置きます。
2. Android、macOS、Windows の Chrome、または macOS、Windows の Edge で[コントローラー](https://wuwa.south-wall.com/?lang=ja)を開きます。
3. **応援棒を接続**を選びます。
4. 自分の機器 `JFKJ-FBFB` を選びます。
5. 青い光が 3 回点滅するまで待ちます。
6. 色やエフェクトを選びます。

研究用サンプルは基板 `HE-750G24`、ファームウェア `V4.1.8` です。別の製品やバージョンの動作は保証していません。

iPhone と iPad の Safari、Chrome にはネイティブ Web Bluetooth がなく、画面プレビューのみ利用できます。接続にはBluefyブラウザーのインストールが必要です。通常の Safari や Chrome が直接対応するという意味ではありません。

## 言語を選ぶ

サイトはブラウザーの言語から中国語、英語、日本語を選びます。対応する言語がなければ英語を使います。中国語は簡体字です。

言語メニューで変更できます。変更時にページは再読み込みされず、応援棒との接続や再生は継続します。保存できる場合は、次回も手動で選んだ言語を使います。

共有する URL に `?lang=ja`、`?lang=en`、`?lang=zh` を付けると、その言語を指定できます。この指定は保存済みの選択より優先します。保存も URL 指定もない場合は、ブラウザーの優先言語一覧で最初に対応する言語を使います。

## 光を変える

色環または色のボタンで色を選び、明るさを調整します。

| 種類 | 動作 |
|---|---|
| 本体エフェクト | 応援棒が内部タイマーで再生します。固定プリセットでは、一部の色や速度を変更できません。 |
| 拡張エフェクト | ブラウザーが色の変化を送信します。ページや Bluetooth の動作に依存します。 |
| 音楽 | 音声を端末内で解析し、光に変換します。音声をサイトにアップロードしません。 |

音楽では、ファイル、タブの共有音声、またはマイクを選びます。利用できる音源はブラウザーにより異なります。マイクや共有音声にはブラウザーの許可が必要です。

速い点滅は初期状態では無効です。必要な場合にだけ有効にしてください。

## 終了

光を消すには消灯ボタンを使います。Bluetooth を切断するだけでは、光が消えない場合があります。

本体エフェクトは応援棒側で動作します。ブラウザーを閉じる前に、停止または消灯してください。

## ローカルで使う

Node.js 24 と Python 3 を用意し、リポジトリのルートで実行します。

```sh
npm test
npm run build
python3 -m http.server 8765 -d dist
```

[localhost:8765](http://localhost:8765/?lang=ja) を開きます。`web/` を直接配信すると、共通ヘッダーとフッターが入りません。先にビルドしてください。

詳細は[SDK（英語）](../SDK.md)と[デプロイ（英語）](../DEPLOYMENT.md)を参照してください。
