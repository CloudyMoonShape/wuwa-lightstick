# 通知ブリッジ

[English](README.md) · [中文](README.zh-CN.md) · [技術構成と開発ガイド](DEVELOPMENT.md)

Mac の通知からアプリ識別子、レコード ID、時刻だけを読み取り、プライベートな Tailscale ネットワークと SSH を通して、ライトスティックの近くにある Linux ホストへ送ります。通知本文は読み取りません。Web コントローラーとは別の任意ツールです。

設定と導入手順は英語版を参照してください。両方のホストで設定例を `~/.config/resonator-notify/config.json` にコピーし、自分のネットワークと機器の値を指定します。実際の設定をコミットしないでください。Mac のバックグラウンド Python にはフルディスクアクセス、Linux には BlueZ と Bleak が必要です。

Claude はオレンジ、ChatGPT/Codex は白、WeChat は緑、Lark は空色、Muse は紫、Telegram はピンクです。5.5 秒の内蔵呼吸エフェクト後、設定色の 30% から 120 秒かけて消灯します。保持時間はありません。別のアプリの新しい通知が現在の効果を置き換えます。同じアプリの通知はまとめます。関連レコードがすべて消えた場合は 2 秒で消灯します。レコードの消失は既読を保証しません。

設定したタイムゾーンの 08:00–24:00 に、送信元 Mac が家庭のサブネット経由で直接接続されている場合だけ動作します。在宅判定を 30 分キャッシュします。本人の位置は確認しません。BLE 接続は維持しますが、再接続時に認証の青い点滅が発生することがあります。

フェードには明るさの段差が残ります。白色のモード切り替えで点滅する場合があります。macOS 通知データベースは非公開のシステム仕様です。対象環境で検証してください。リポジトリのソース公開ライセンスと商用制限が適用され、無制限のオープンソースライセンスではありません。
