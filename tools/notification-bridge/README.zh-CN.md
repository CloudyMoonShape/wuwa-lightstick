# 通知桥接

[English](README.md) · [日本語](README.ja.md) · [技术栈与开发指南](DEVELOPMENT.md)

Mac 只读取通知的应用标识、记录编号和时间，通过私人 Tailscale 网络及 SSH，把事件发给灯棒附近的 Linux 蓝牙控制端。不会读取通知正文。此工具独立于网页控制器。

配置与安装步骤见英文主文档。将示例配置复制到两台机器的 `~/.config/resonator-notify/config.json`，填写自己的设备与网络参数。不要提交实际配置。Mac 后台 Python 进程需要完全磁盘访问权限；Linux 需要 BlueZ 和 Bleak。

Claude 对应橘黄色，ChatGPT/Codex 对应白色，微信对应绿色，Lark 对应天蓝色，Muse 对应紫色，Telegram 对应粉红色。原生呼吸运行 5.5 秒，随后直接从设定颜色的 30% 渐灭两分钟，没有保持阶段。不同来源的新通知接管旧灯效；同来源通知合并。相关通知记录全部消失后，两秒快速渐灭。消失并不一定表示用户已读。

仅在配置时区的 08:00–24:00、来源电脑通过家庭网段直连时允许提示。在家结果缓存 30 分钟，并不证明本人在家。蓝牙在提示间保持连接，首次认证或重连可能闪蓝灯。

渐灭仍有亮度台阶，白光切换可能闪一下；呼吸期间清除通知时只能估算亮度。通知数据库是未公开系统接口，需要在目标 macOS 上验证。使用同仓库的源码可查看许可证，商业限制仍然有效，不属于无限制开源许可。
