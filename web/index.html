装好电池，在蓝牙弹窗中选择 JFKJ 开头的设备。蓝灯闪完后即可操纵，网页灯效使用时请保持页面在前台。

找不到设备时，请关闭其他已连接它的网页或程序，确认系统蓝牙与浏览器权限已开启，靠近棒子后重试。iPhone / iPad、微信里打开，或手机浏览器连不上时，见。

连接说明

  
遥控用的是浏览器提供的「网页蓝牙」，和手机能不能连蓝牙耳机无关。连不上时仍可在屏幕上试玩。

  
选择你的设备
    
    
    
    
    
  

  

    
Windows、Mac 用 Chrome 或 Edge 打开本站，点「连接应援棒」即可。

    
Mac 的 Safari、电脑版 Firefox 不能连接。

  

  

    
用 Chrome 或 Edge 打开本站。首次连接时允许「附近的设备」或「位置」权限。

    
手机自带浏览器、UC、夸克、QQ 浏览器等大多不能连接；连不上时复制网址，换到 Chrome 或 Edge 打开。

    

  

  

    
iPhone / iPad 的 Safari、Chrome 不能直接连接。可以使用支持网页蓝牙的 Bluefy，或 Safari 的 beacio 扩展。以下截图以 Bluefy 为例；两个工具都由第三方开发。

    
方法一：Bluefy（最省事）



  1. 安装 Bluefy
    在 App Store 找到 Bluefy，核对开发者 PNN Soft。
    去 App Store
  2. 允许蓝牙
    出现系统权限提示时，点 Allow（允许）。
  3. 选择灯棒
    打开本站，点「连接应援棒」，选择 JFKJ-FBFB。无需开启后台连接。
  4. 等待蓝灯
    Bluefy 显示 connected 后，继续等待网页完成蓝灯验证。
  5. 开始控制
    网页显示「已连接」后，再调色或播放灯效。

    
方法二：beacio（继续用 Safari）
